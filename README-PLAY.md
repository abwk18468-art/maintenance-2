# دليل النشر على Google Play (سوق Play)

الفكرة: التطبيق موقع PWA يعمل على رابط HTTPS، ونغلّفه بتطبيق أندرويد (Trusted Web Activity) عبر **PWABuilder**. عند تثبيته يفتح المالك شاشة الترحيب، يضغط «أنا مالك محل أو مكتب» فيُنشأ **حساب المدير**، ثم يدعو **المحاسب** و**الموظفين** برمز/رابط ويحدد صلاحية كل واحد من «الموظفون».

---
## 1) قبل أي شيء (إلزامي)
1. **انشر قواعد Firestore** من `firestore.rules` (Firebase Console ← Firestore ← Rules ← Publish) ثم جرّبها بـ Rules Playground. هذه القواعد هي التي تعزل كل محل عن غيره.
2. افتح **Authentication** وفعّل «البريد وكلمة المرور». ويُفضَّل تفعيل حد للتسجيلات وإعدادات حماية البريد.
3. **قيّد مفتاح API** (Google Cloud ← APIs & Services ← Credentials) بنطاق موقعك فقط، وفعّل **App Check** قبل الإطلاق العام.
4. غيّر خطة Firebase إلى **Blaze** مع **تنبيه ميزانية**، لأن الخطة المجانية لا تكفي عدداً كبيراً من المحلات. كل محل يقرأ مستنداته عند الفتح، فتزداد التكلفة مع عدد المستخدمين.
5. صفحتا `privacy.html` و`delete-account.html` معبّأتان باسمك وبريدك. راجعهما مع مختص قانوني، وحدّث التاريخ فيهما عند أي تعديل.

## 2) الاستضافة: استخدم Firebase Hosting (لا GitHub Pages)
GitHub Pages **غير مسموح** باستخدامه لتشغيل موقع تجاري أو برنامج كخدمة (SaaS) بحسب شروطه، وتطبيقك سيُباع/يُوزَّع للمحلات، فقد يوقفه GitHub. كما أن `.well-known` يتطلب مستودعاً خاصاً بالجذر. لذلك الأفضل **Firebase Hosting**: نفس مشروعك الحالي، رابط ثابت HTTPS مثل `https://sabana-hassan-saddam.web.app`، ويخدم `.well-known` ويضبط رؤوس التخزين المؤقت (ملف `firebase.json` جاهز).

**طريقتان للنشر:**
- **أ) من كمبيوتر (مرة واحدة ثم أمر لكل تحديث):** ثبّت Node.js ثم `npm i -g firebase-tools` ثم `firebase login` ثم داخل مجلد المشروع `firebase deploy --only hosting`.
- **ب) من الجوال عبر GitHub (تحديث تلقائي عند الرفع):** ملف `.github/workflows/firebase-hosting.yml` جاهز في المشروع.
  1. أنشئ مستودعاً خاصاً على GitHub وارفع إليه محتوى المجلد (`firebase.json` و`.firebaserc` ومجلد `public` بكل ملفاته ومجلد `.github`).
  2. في Firebase Console ← إعدادات المشروع ← **Service accounts** ← «Generate new private key» (يُنزَّل ملف JSON).
  3. في GitHub ← Settings ← Secrets and variables ← Actions ← New secret باسم `FIREBASE_SERVICE_ACCOUNT` والصق **كامل** محتوى ملف JSON.
  4. كل رفع لملفات `public` على فرع `main` ينشر الموقع تلقائياً. إن ظهر خطأ صلاحيات أضف للحساب دور **Firebase Hosting Admin** من Google Cloud ← IAM.
- أول مرة قد تحتاج تفعيل Hosting من Firebase Console ← Hosting ← Get started.

بعد النشر تحقق أن هذه الروابط تفتح: `/` و`/privacy.html` و`/delete-account.html` و`/.well-known/assetlinks.json`.

الملفات المطلوبة داخل `public`: `index.html` `manifest.json` `sw.js` `icon-192.png` `icon-512.png` `icon-maskable-512.png` `track.html` `statement.html` `privacy.html` `delete-account.html` `firebase-config.js` ومجلد `.well-known`.

## 3) التغليف بتطبيق أندرويد
1. افتح **pwabuilder.com** وأدخل رابط موقعك، وأصلح أي تحذير يظهر.
2. اختر **Package for stores ← Google Play**.
3. **Package ID** مثل `com.اسمك.accounting` (دائم ولا يتغير). اسم التطبيق: كما تريده أن يظهر.
4. اجعل PWABuilder ينشئ **مفتاح التوقيع** (احتفظ بالملف وكلمة المرور في مكان آمن، فبدونهما لا تستطيع التحديث).
5. نزّل الحزمة: فيها `.aab` للرفع، وملف `signing-key-info` فيه بصمة **SHA-256**.
6. ضع البصمة في `public/.well-known/assetlinks.json` (استبدل `PACKAGE_NAME_HERE` و`SHA256_FINGERPRINT_HERE`) وانشره. بعد أول رفع على Play يظهر مفتاح Google الخاص بالتطبيق في Play Console ← App integrity ← App signing، **أضف بصمته أيضاً** في المصفوفة (فاصلة بين البصمتين) وإلا ظهر شريط المتصفح في أعلى التطبيق.

## 4) Play Console
1. أنشئ حساب مطوّر (رسوم تسجيل مرة واحدة). **حسابات الأفراد الجديدة** (بعد 13 نوفمبر 2023) تحتاج **اختباراً مغلقاً بـ 12 مختبراً لمدة 14 يوماً متصلة** قبل طلب الإنتاج. حسابات المؤسسات معفاة لكنها تحتاج رقم D-U-N-S.
2. أنشئ تطبيقاً جديداً، ثم **Testing ← Closed testing**، وارفع الـ `.aab`، وأضف عناوين Gmail للمختبرين.
3. بيانات المتجر: اسم، وصف قصير وطويل، أيقونة 512×512، صورة مميزة 1024×500، 4 لقطات شاشة على الأقل، الفئة (أعمال/مالية).
4. **Data safety:** البيانات المجموعة: البريد، الاسم، المحتوى الذي ينشئه المستخدم (الزبائن والمبيعات)، الصور، معرّف الجهاز. مشفّرة أثناء النقل. اختر «يتوفر حذف الحساب» وضع رابط `delete-account.html`.
5. **سياسة الخصوصية:** رابط `privacy.html`.
6. **الجمهور المستهدف:** بالغون، وليس للأطفال. أكمل استبيان تصنيف المحتوى.
7. بعد استيفاء الاختبار المغلق اطلب **الوصول للإنتاج**.

## 5) بعد النشر
- **التحديثات:** التطبيق يفتح موقعك، فكل ما ترفعه يصل المستخدمين دون تحديث على Play. ويظهر شريط «يوجد إصدار جديد». ولا تحتاج رفع `.aab` جديد إلا لتغيير الأيقونة أو الاسم أو رقم الحزمة.
- راقب تكلفة Firebase أسبوعياً في أول شهر.
- تأكد من نسخ احتياطي لمفتاح التوقيع وبيانات حساب Play.
